# Student Result App

A minimal React app (Vite) to calculate student results from marks.

Features:
- Input student name, class and marks for 5 subjects
- Calculates total, average, grade and pass/fail
- Print result and Download simple text report
- Ready to deploy on Netlify / Vercel / any static host

## Run locally
1. npm install
2. npm run dev
3. Open http://localhost:5173

## Build
- npm run build
